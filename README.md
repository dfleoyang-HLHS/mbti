# mbti
16型人格測驗

## 16型MBTI性格探索

一個免費、免註冊的線上性格探索測驗，幫助成人了解自己的性格偏好、工作風格與職涯發展方向。

**網站網址**：<https://dfleoyang-hlhs.github.io/mbti/>（GitHub Pages 開啟後生效）

### 功能

- **60 題完整版測驗**：5 點量表（非常不同意～非常同意），約 10～12 分鐘完成
- **四個向度**：能量來源（E／I）、資訊接收（S／N）、決策方式（T／F）、生活態度（J／P）
- **簡易結果頁**：作答完成後立即顯示 16 型類型代碼、類型名稱、四向度傾向長條圖與解讀引導
- **完整報告**：類型概述、優勢、可能的盲點、成長建議、工作風格、溝通與合作、適合的工作環境、職涯方向參考
- **PDF 下載**：一鍵下載完整報告，或使用「列印／另存 PDF」
- **跨裝置**：手機、平板、電腦皆可使用，支援深色模式
- **作答進度暫存**：中途離開可繼續作答（僅存於使用者自己的瀏覽器）

### 隱私

所有計分都在使用者的瀏覽器中完成，網站**不蒐集、不傳送任何作答資料或個人資料**。

### 專案結構

| 路徑 | 說明 |
|---|---|
| `index.html` | 首頁與作答說明 |
| `quiz.html` | 作答頁 |
| `result.html` | 簡易結果頁 |
| `report.html` | 完整報告與 PDF 下載 |
| `data/questions.json` | 題庫（60 題）與計分規則 |
| `data/types.json` | 16 型類型描述與共用文字 |
| `docs/PLAN.md` | 專案企劃書 |
| `docs/QUESTIONS.md` | 題庫說明（審題用） |
| `docs/TYPES.md` | 類型描述（審閱用） |

### 本機預覽

網站需透過網頁伺服器開啟（直接雙擊 HTML 檔無法載入題庫資料），例如：

```bash
python3 -m http.server 8000
# 再以瀏覽器開啟 http://localhost:8000/
```
