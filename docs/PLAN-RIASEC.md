## 一、背景與目標

「16型MBTI性格探索」已經上線，能幫助使用者了解自己的**性格偏好與工作風格**。不過，性格類型對職業選擇的預測證據較弱。生涯輔導領域更常用 **Holland 興趣類型理論（RIASEC）** 來探索職業方向。

本企劃新增第二個網站「Holland 職業興趣探索」，與現有網站互相連結：

| | 16型MBTI性格探索（已上線） | Holland 職業興趣探索（新網站） |
|---|---|---|
| 回答的問題 | 我習慣**怎麼做事**、怎麼和人互動？ | 我對**哪一類工作活動**有興趣？ |
| 理論基礎 | 榮格心理類型／MBTI 類型理論 | Holland 職業興趣類型理論（RIASEC） |
| 結果形式 | 四字母類型代碼（如 INFJ） | 三字母興趣代碼（如 SAI） |
| 職涯上的用途 | 工作風格、適合的工作環境 | 職業與領域的選擇方向 |

### 三大目標
1. **認識職業興趣**：了解自己在六種興趣類型上的強弱，取得三字母興趣代碼。
2. **連結職涯方向**：依興趣代碼提供相關的工作活動、工作環境與職業領域**作為參考**。
3. **整合自我了解**：兩個測驗都完成時，在整合報告子網頁中，從「工作風格 × 興趣方向」兩個角度看自己。

### 不做的事（範圍界定）
- 不提供心理診斷，也不提供「最適合你的唯一職業」這類結論。
- 不建議企業或機構以測驗結果作為招募、任用、升遷或考績的依據。

- **各自獨立**：各有首頁、作答、結果與完整報告，可以只做其中一個。
- **互相連結**：兩個網站的首頁與結果頁都放上對方網站的介紹與連結。

### 為什麼方案 B 仍能做整合報告
兩個網站都在 `dfleoyang-hlhs.github.io` 網域下，瀏覽器視為**同一個來源**（網域相同，只是路徑不同），因此可以讀取彼此存在瀏覽器中的測驗結果。資料仍然**只存在使用者自己的瀏覽器**，不會傳到任何伺服器。

### 方案 B 的取捨
- 優點：兩個網站獨立管理、各自有清楚的網址與名稱，日後可以分開推廣。
- 代價：共用的樣式與功能需要在兩個 repo 分別維護。對策：在兩個 repo 的文件中記錄共用部分，修改時同步調整。

## 四、Holland 理論架構

### 六種興趣類型

| 代碼 | 類型 | 喜歡的活動 | 常見的工作環境 |
|---|---|---|---|
| R | 實用型（Realistic） | 動手操作、使用工具與機械、戶外與體能活動 | 有具體成果、可動手的環境 |
| I | 研究型（Investigative） | 觀察、分析、探究原理、解決抽象問題 | 重視知識與思考的環境 |
| A | 藝術型（Artistic） | 創作、設計、表達想法與感受 | 自由、重視創意的環境 |
| S | 社會型（Social） | 教導、協助、照顧、輔導他人 | 以人際互動與助人為主的環境 |
| E | 企業型（Enterprising） | 領導、說服、談判、經營管理 | 追求目標、影響他人的環境 |
| C | 事務型（Conventional） | 整理資料、依循規範、處理數字與細節 | 制度清楚、講求精確的環境 |

### 六角形模型
六種類型依 R → I → A → S → E → C 的順序排成六角形：
- **相鄰**的類型性質較接近（例如 R 與 I）。
- **相對**的類型性質差異最大（例如 R 與 S、I 與 E、A 與 C）。

### 結果的三個解讀指標

| 指標 | 意義 | 本專案的呈現方式 |
|---|---|---|
| 興趣代碼 | 分數最高的三型，依高低排列 | 例如 `SAI`，結果頁以大字顯示 |
| 一致性 | 代碼前兩碼在六角形上是否相鄰 | 相鄰時說明「興趣方向較一致」；相對時說明「興趣多元，可尋找能結合兩者的工作」 |
| 分化程度 | 最高分與最低分的差距 | 差距小時提醒「興趣分布平均，可再透過實際經驗探索」 |

## 五、題庫：學術公開題目的選用與中文化

### 候選來源（採用前須逐一查證）

| 候選來源 | 內容 | 待查證事項 |
|---|---|---|
| **公開 RIASEC 標記量表**：Armstrong, Allison & Rounds（2008），*Journal of Vocational Behavior*，以國際人格題庫（IPIP）方式發表的公開領域題目 | 六型各 8 題，共 48 題；題目為具體工作活動 | 原始文獻的題目清單、公開領域聲明、英文版信效度數據 |
| **O*NET Interest Profiler 短版**：美國勞工部 O*NET 計畫發展 | 六型各 10 題，共 60 題；題目為具體工作活動 | 使用授權條款：是否允許翻譯、修改，以及放在第三方網站；必要的來源標示方式 |

**選用原則**
1. 授權允許「免費使用＋翻譯＋放在公開網站」。
2. 有已發表的信效度證據。
3. 題目內容適合台灣成人。

兩個來源都符合時，優先選用**授權最明確、限制最少**者；都不符合時，回到「自行撰寫」並告知你。

### 中文化程序（依 ITC 測驗翻譯與調適指引）
1. **正向翻譯**：兩位譯者各自將英文題目譯成中文。
2. **整合**：比對兩份譯稿，整合成第一版中文題目。
3. **回譯**：由未看過英文原題的第三位譯者將中文譯回英文，比對與原題的意思是否一致。
4. **文化調適**：把台灣成人不熟悉的活動換成意義相同的在地活動，例如美國特有的職業或場景。每一處調整都要記錄原題、修改後的題目和修改理由。
5. **專家審閱**：請生涯諮商或心理專業人員審閱。
6. **認知訪談**：請 5～10 位成人邊讀邊說出對題目的理解，確認沒有誤解。

### 作答與分階段
- **量表**：依原量表的作答方式，預期為 5 點喜歡程度量表（1 非常不喜歡～5 非常喜歡），查證原始文獻後確認。
- **分階段**：沿用現有設計分 6 個階段，每個階段包含六型的題目，依 R → I → A → S → E → C 輪流出題。
  - 選用 48 題版：每階段 8 題。
  - 選用 60 題版：每階段 10 題。
- **計分方向**：興趣量表詢問對各類活動的喜好，每題只對應一種類型，全部正向計分。

### 審題文件
`docs/HOLLAND-QUESTIONS.md` 會並列「英文原題／中文翻譯／回譯／文化調適說明」，供專家審閱。

## 六、計分方式

以「每型 n 題」表示，48 題版 n = 8，60 題版 n = 10。

1. 每型 n 題加總，原始分數範圍 n～5n。
2. 換算為 0～100 分：`(原始分數 − n) ÷ 4n × 100`。
3. **興趣代碼**：取分數最高的三型，依高低排列。
4. **並列處理**：分數相同時，依 R、I、A、S、E、C 的順序排列，並在結果中標示「並列」，提醒使用者兩種排列都適用。
5. **一致性**：代碼前兩碼在六角形上相鄰為「高」、隔一型為「中」、相對為「低」。
6. **分化程度**：最高分與最低分相差小於 20 分（0～100 分制）時，標示「興趣分化不明顯」。此門檻為暫定值，試測後依資料調整。
7. **整體偏低提醒**：六型分數都低於 50 分時，提醒使用者「目前對各類活動的興趣普遍不高，可能與近期狀態有關，建議日後再測或與專業人員討論」。
8. 若原始文獻有建議的計分方式，以原始文獻為準，並在 `docs/` 中記錄差異。

## 七、結果呈現流程

沿用 16 型網站的兩層設計。

### 第一層：簡易結果頁
1. **興趣代碼**：大字顯示三字母代碼（例如 `SAI`）與名稱（例如「社會型－藝術型－研究型」）。
2. **六角形雷達圖**：以六角形呈現六型分數，直接對應 Holland 的六角形模型。
3. **前三型的簡短說明**。
4. **解讀提示**：一致性、分化程度與整體偏低提醒（符合條件時才顯示）。
5. **簡易引導**與「查看完整報告」「下載完整報告（PDF）」按鈕。
6. **整合報告入口**：
   - 已完成 16 型測驗：顯示「查看整合報告」。
   - 尚未完成：顯示「完成 16型MBTI性格探索，解鎖整合報告」，並連到 16 型網站。

### 第二層：完整報告（可線上閱讀，也可下載 PDF）
- 興趣代碼、雷達圖與六型分數。
- 前三型的詳細說明：喜歡的活動、能力傾向、適合的工作環境。
- **職業領域參考**：依前三型列出相關的職業領域與職業範例，並附上職涯提醒。
- 解讀指標說明：一致性與分化程度。
- 延伸建議：職業資訊查詢、實地體驗（見習、志工、短期課程）、與職涯諮詢人員討論。
- 題目來源與翻譯說明、產生日期與免責聲明。

### 職業領域資料
- 依六型分別撰寫職業領域與職業範例，以台灣常見的職業名稱為主。
- 可參考美國勞工部 O*NET 職業資料庫中各職業的興趣代碼；**使用前須確認其授權條款並依規定標示來源**。

| 方式 | 說明 | 適用情境 |
|---|---|---|
| 瀏覽器暫存 | 兩個網站把「最近一次測驗結果」存在使用者的瀏覽器中，整合頁直接讀取 | 同一支手機或同一台電腦、同一個瀏覽器完成兩個測驗 |
| 網址參數 | 整合頁網址同時帶有兩個測驗的結果，例如 `combined.html?m=…&h=…` | 換裝置、加入書籤、分享給諮詢人員 |

- 網站仍然**不蒐集、不傳送任何作答資料**。兩個網站的隱私說明都會補充：「最近一次結果會存在你的瀏覽器中，以便產生整合報告；清除瀏覽器資料即可刪除。」
- 兩個網站存放資料的名稱各自加上前綴（`mbti-`、`holland-`），避免互相覆蓋。

### 16 型網站需要配合的調整
1. 完成測驗時，把結果（四個向度的原始分數）存進瀏覽器。
2. 結果頁與報告頁加上 Holland 網站的介紹，以及整合報告的連結。
3. 隱私說明補上第 1 點的說明。

### 報告內容
1. **兩個代碼並列**：例如 `INFJ × SAI`，並附上兩個網站各自完整報告的連結。
2. **兩個角度的對照**：
   - 興趣方向（Holland）：你可能想做什麼類型的事。
   - 工作風格（16 型）：你可能用什麼方式去做。
3. **組合解讀**：依 16 型的 8 端 × Holland 六型，撰寫 48 則簡短的對照說明，報告中只顯示與使用者結果相關的部分。例如「社會型 × 內向」：可能較適合一對一或小團體的助人工作，例如個別輔導、教練、照護。
4. **提醒**：兩個測驗都只是自我探索的參考。整合結果代表「值得探索的方向」，不是唯一答案。
5. **PDF 下載**：與兩個網站的完整報告相同。

## 十、隱私與倫理

- 兩個網站與整合報告都**不蒐集、不傳送任何作答資料**。
- 最近一次結果只存在使用者自己的瀏覽器，隱私說明會告知用途與刪除方式。
- 免責聲明放在首頁、結果頁與 PDF 報告。內容包括：僅供自我探索參考，不宜作為招募、任用、升遷或職涯決策的唯一依據，以及兩個測驗的理論來源、題目來源與非官方聲明。
- 職業領域與整合說明都避免性別、年齡或身分的刻板印象，也不做「某類型不適合某職業」的論述。

## 十一、開發時程（分 8 階段）

## 十二、品質評估指標

| 指標 | 標準 |
|---|---|
| 內部一致性 | 六型各自的 Cronbach's α ≥ 0.70 |
| 重測一致性 | 間隔數週重測，各型分數的相關係數，以及前兩碼的一致比例 |
| 六角形結構 | 六型之間的相關矩陣中，相鄰類型的相關應高於相對類型 |
| 與英文原版比較 | 中文版的信度與六角形結構，與原始文獻報告的數據相近 |
| 與 16 型的關聯 | 預期為中低程度的相關，用來確認兩個測驗相關但不重複 |
| 使用者回饋 | 「描述符合我」的主觀評分、作答時間、完成率 |

## 十三、風險與對策

| 風險 | 對策 |
|---|---|
| 題目授權不明確或不允許翻譯 | 第 2 階段先完成查證並保留紀錄；不符合條件的來源不採用 |
| 翻譯後意思改變或不符合台灣情境 | 依 ITC 指引進行正向翻譯、回譯、文化調適與認知訪談 |
| 中文版信效度未知 | 上線初期標示試行版；試測後依資料修題 |
| 結果被過度解讀為「只能做某職業」 | 呈現六型分數而不只是代碼；加註一致性與分化程度；附上職涯提醒 |
| 職業範例帶有刻板印象或過時 | 以活動描述為主，職業範例定期檢視更新 |
| 兩個 repo 的共用程式不同步 | 文件記錄共用部分；修改其中一邊時檢查另一邊 |
| 瀏覽器暫存被清除或換裝置 | 整合報告同時支援網址參數 |
