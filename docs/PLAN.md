## 二、專案目標與定位

### 目標使用者
- 18 歲以上成人，包含：在職者、轉職者、大專學生、團隊主管與人資夥伴（作為團隊溝通參考）。

### 三大目標
1. **認識自己**：了解自己在四個向度上的偏好與強度。
2. **理解他人**：理解不同類型在溝通、決策與合作上的差異，改善職場與人際互動。
3. **職涯發展參考**：提供工作風格、適合的工作環境與職涯方向**作為參考**，並引導使用者搭配其他工具（如 Holland 興趣量表）及專業職涯諮詢。

### 不做的事（範圍界定）
- 不提供心理健康診斷。
- 不建議企業以本測驗結果作為招募、任用或考績的依據。

## 三、理論架構：四個向度

| 向度 | 兩端 | 測量重點 |
|---|---|---|
| 能量來源 | 外向 E ↔ 內向 I | 從與人互動或從獨處中獲得能量 |
| 資訊接收 | 實感 S ↔ 直覺 N | 重視具體事實與經驗，或整體模式與可能性 |
| 決策方式 | 思考 T ↔ 情感 F | 以邏輯原則為主，或以價值與人際影響為主 |
| 生活態度 | 判斷 J ↔ 感知 P | 偏好計畫與結構，或彈性與開放 |

四向度組合為 16 種類型。

## 四、測驗設計

1. **題數（完整版）**：每向度 15 題，共 60 題，作答約 10～12 分鐘。
2. **題型**：**5 點量表**——1 非常不同意、2 不同意、3 普通／中立、4 同意、5 非常同意。
3. **正反向題平衡**：每向度 15 題中，8 題「同意」代表一端、7 題代表另一端（兩端輪替分配，四個向度合計兩端各 30 題），降低一律同意的作答偏誤。
4. **情境化**：題目以成人熟悉的情境撰寫，例如會議討論、專案規劃、團隊合作、假日安排、面對截止期限。
5. **計分方式**：
   - 反向題先轉換（1↔5、2↔4），使每題分數都朝向同一端（例如 E 端）。
   - 每向度 15 題原始分數範圍 15～75，換算傾向值：`(原始分數 − 15) ÷ 60 × 100%`；另一端為 100% 減去此值。
   - 傾向值 > 50% 取該端字母；剛好 50% 時，沿用 MBTI 早期計分的平手規則歸給 I、N、F、P。
   - 四個字母組合成使用者的**類型代碼**（例如 `INFJ`），一律給出明確的四字母代碼。
   - 傾向值落在 45～55% 的向度，在結果中另外標示「**此向度偏好不明顯**」，提醒使用者該字母僅為些微傾向。
6. **題目品質流程**：撰寫題庫 → 專家審題（心理、諮商或職涯專業人士）→ 小規模試測 → 統計分析 → 修題。

## 五、結果呈現流程

作答結束後分為兩層：

### 第一層：簡易結果頁（作答完成立即顯示）

1. **類型代碼**：以大字顯示四字母代碼（例如 `INFJ`）與類型名稱。
2. **一句話特質描述**。
3. **四向度強度長條圖**，偏好不明顯的向度加註提示。
4. **簡易引導**：
   - 2～3 句說明如何解讀類型代碼（「代表偏好，不代表能力」）。
   - 「想更深入了解自己？」→ **【查看完整報告】** 按鈕。
   - **【下載完整報告（PDF）】** 按鈕。
5. 免責聲明。

### 第二層：完整報告（可線上閱讀，也可下載）

每一型的完整報告包含：

- 類型代碼、類型名稱與一句話特質描述
- 四向度**強度長條圖**與各向度百分比
- **優勢**與**可能的盲點／成長建議**（正向、不貶抑的語氣）
- **工作風格**：偏好的工作節奏、決策方式、在團隊中常扮演的角色
- **溝通與合作提示**：與不同類型共事的建議
- **適合的工作環境與職涯方向參考**，並附註：「同一類型的人分布於各行各業；類型代表偏好，不代表能力。職涯選擇請綜合興趣、能力、價值觀與實際經驗。」
- **延伸建議**：搭配 Holland 興趣量表、職能盤點或職涯諮詢
- 報告產生日期與免責聲明（含商標聲明）

## 六、技術架構

| 項目 | 規劃 | 理由 |
|---|---|---|
| 主機 | GitHub Pages | 免費，與 repo 整合，推送後自動部署 |
| 技術 | 純 HTML + CSS + JavaScript（靜態網站） | 無需伺服器，易於維護 |
| 資料格式 | `questions.json`（題庫）、`types.json`（類型描述） | 內容與程式分離，修改內容不需改程式 |
| 計分 | 瀏覽器端計算 | **不蒐集、不傳送任何個人資料** |
| 完整報告下載 | 在瀏覽器端產生 PDF：主要方案用 html2pdf.js 一鍵下載；備援方案為列印樣式表（CSS `@media print`），由使用者「列印 → 另存為 PDF」 | 不需伺服器。html2pdf.js 會把頁面轉成圖片再存成 PDF，中文字不需另外嵌入字型（代價是 PDF 內文字無法選取）；列印方式則保留可選取的文字 |
| 結果分享 | 以網址參數記錄類型代碼與四向度百分比 | 不需資料庫，重新開啟網址即可再看報告 |
| 介面 | 響應式設計（手機優先）、正體中文、作答進度條 | 多數使用者以手機作答 |
| 無障礙 | 足夠字級與對比、可鍵盤操作 | 符合無障礙原則 |

## 七、隱私與倫理

- **免責聲明**置於首頁、結果頁與下載的 PDF 報告：本測驗僅供自我探索參考，非心理診斷工具，不宜作為招募、任用、升遷或職涯決策的唯一依據。
- 第一版**完全不蒐集作答資料**。若日後需蒐集統計資料，須依《個人資料保護法》告知蒐集目的、取得同意，並進行去識別化。
- 避免標籤化與刻板印象（例如「某型不適合當主管」之類的論述）。

## 九、品質評估指標

- **內部一致性**：各向度 Cronbach's α ≥ 0.70。
- **重測一致性**：間隔數週重測的類型一致比例，以及各向度分數的相關係數。
- **使用者回饋**：「描述符合我」主觀評分、作答時間、完成率。

## 十、風險與對策

| 風險 | 對策 |
|---|---|
| 商標或著作權爭議（名稱含「MBTI」） | 題目自編；各頁面與報告標示商標聲明及「非官方、無關聯」 |
| 結果被過度解讀或誤用於人事決策 | 呈現傾向強度、標示限制、聲明不適用於招募任用 |
| 題目品質不穩定 | 專家審題、試測、統計分析後修題 |
| 標籤化與刻板印象 | 正向語氣描述，強調「偏好不等於能力」 |
